# Tempero das Meninas - Cardapio Online

Projeto React com Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereco mostrado pelo Vite, normalmente `http://127.0.0.1:5173/`. Nao abra o `index.html` diretamente pelo explorador de arquivos, pois projetos React com Vite precisam do servidor para carregar os modulos.

Para gerar a versao de producao:

```bash
npm run build
```

O site inclui:
- Cardapio responsivo para celular;
- Carrinho com quantidades e total;
- Carrinho recolhido no celular para nao cobrir o cardapio;
- Busca e filtros por categoria;
- Etiquetas de produto e preco promocional via banco;
- Campo de nome e endereco;
- Pedido montado e enviado pelo WhatsApp (92) 99325-0320;
- Combo especial por R$ 45,00.

## Supabase

1. Crie um projeto no Supabase.
2. Execute o arquivo `supabase-schema.sql` no SQL Editor.
3. Crie um usuario em Authentication > Users para acessar o painel.
4. Copie `.env.example` para `.env.local` e preencha a URL e a chave anon.
5. Abra `/#admin` para cadastrar produtos. Todo produto novo comeca como rascunho e so aparece ao publica-lo.

As imagens ficam em `imagens/`. Para a Vercel, configure as mesmas variaveis `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY` nas Environment Variables. A pasta `dist/` gerada pelo build pode ser publicada em um servico de hospedagem estatica.
